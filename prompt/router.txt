* Use LangChain chat-model adapters for the LLM.

* Add an LLM-based router agent that receives the user_request and selects exactly one agent: agent1 OR agent2.
* Use LangGraph conditional edges to route the user_request to the selected agent.

* The user_request, router output, and selected agent output must not be passed directly to summary_agent.
